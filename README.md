# SkillXpAnnouncer 技能经验播报

《骑马与砍杀2：霸主》(Bannerlord) v1.2.12 模组：在左下角信息栏播报角色获得的技能熟练度经验与角色升级经验，并可在战斗中显示实时的经验/伤害统计表。

## 功能

- **经验播报**：播报技能熟练度经验（如 `XXX的单手武器+10(990)`）与角色升级经验（如 `XXX的角色经验+300(4500)`）。
- **战斗中合并播报**：同一角色、同一技能在合并间隔内的经验合并为一条，避免刷屏。
- **战斗统计表**：战斗中在屏幕指定位置显示一个表格，按角色列出：
  - 当前生命 `XXX(100/300)`（可关）
  - 本场总伤害 `总伤9999`（可关，小数取整）
  - 角色经验、技能熟练度增长总额
  - 支持按总伤排序（降序）、玩家行置顶、角色数量上限、玩家行特殊颜色
- 可配置播报范围：仅玩家 / 仅队友 / 全部。

## MCM 设置

| 分组 | 设置 |
| --- | --- |
| 技能经验播报 | 启用（分组开关）、播报范围、合并间隔、播报技能/角色经验、余量显示 |
| 战斗统计 | 显示表格（分组开关）、显示队友、显示生命、显示总伤、玩家置顶、统计角色上限、按总伤排序、位置 X/Y、宽度、字体大小、透明度 |
| 通用 | 调试信息（输出表格行顺序到日志） |

## 多语言

内置中英双语（游戏语言设置切换），播报正文与统计表标签随语言变化。

## 依赖

- 游戏版本：v1.2.12
- 需要 MCM（Bannerlord.MBOptionScreen v5.10.1+）

## 安装

将 `SubModule.xml`、`Bin`、`ModuleData`、`GUI` 放入 `Modules\SkillXpAnnouncer\`，启用即可。
