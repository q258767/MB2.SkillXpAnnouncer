# SkillXpAnnouncer 技能经验播报

《骑马与砍杀2：霸主》(Bannerlord) v1.2.12 模组：在左下角信息栏播报角色获得的技能熟练度经验与角色升级经验。

## 功能

- 播报技能熟练度经验（如 `XXX的单手武器+10(990)`）与角色升级经验（如 `XXX的角色经验+300(4500)`）。
- **战斗中合并播报**：同一角色、同一技能在合并间隔内的经验合并为一条，避免刷屏。
- 可配置播报范围：仅玩家 / 仅队友 / 全部。
- 可开关是否显示距下一级的余量。

## MCM 设置

| 分组 | 设置 |
| --- | --- |
| 技能经验播报 | 启用、播报范围、合并间隔 |
| 播报内容 | 播报技能经验、播报角色经验、技能余量、角色余量 |

## 多语言

内置中英双语（游戏语言设置切换），播报正文句式也会随语言变化。

## 依赖

- 游戏版本：v1.2.12
- 需要 MCM（Bannerlord.MBOptionScreen v5.10.1+）

## 安装

将 `SubModule.xml`、`Bin`、`ModuleData` 放入 `Modules\SkillXpAnnouncer\`，启用即可。
